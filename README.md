# 👨‍💼 Employee Attendance Analytics Dashboard

## Overview

This project is an interactive Employee Attendance Analytics Dashboard developed using Power BI to analyze employee attendance patterns, work-from-home trends, and leave statistics.

The dashboard helps HR teams and management monitor workforce productivity and make data-driven decisions.

## Business Problem

Managing employee attendance and workforce productivity is critical for organizations.

This dashboard was designed to:

* Monitor employee attendance
* Track work-from-home trends
* Analyze leave patterns
* Measure workforce engagement
* Support HR decision-making
